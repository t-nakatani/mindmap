# マインドマップ試作

MindNode の「ノードの生え方」を Web で再現する試作。ページは `index.html` 1ファイルで、依存はない。
Node のサーバーと CLI を付けて、エージェントからも同じマップを動かせるようにした。

## 動かし方

```sh
node server.mjs
```

ブラウザで http://127.0.0.1:4380 を開く。Node 20 以上。マップは `data/map.json` に保存する。

エージェントや端末からは CLI で操作する。使い方は [AGENTS.md](AGENTS.md) に書いた。

```sh
node cli.mjs show
node cli.mjs add "予算" --under 中心テーマ
node cli.mjs import outline.md --replace
```

## できること

- Tab で子ノード、Enter で兄弟ノードを追加する。中心ノードで Enter を押すと子になる。
- 中心ノードの子は左右に交互に振り分ける。枝ごとに色が付く。
- ノードは自動で配置する。ドラッグしたノードは親からの相対位置で固定し、残りは自動で詰め直す。固定したノードには角に点が付く。
- ノードを別のノードに重ねて離すと、そのノードの子に付け替える。親に重ねると自動配置に戻る。
- 線はベジェ曲線で、階層が深いほど細くなる。配置が変わると線とノードがアニメーションで追従する。
- 背景のドラッグとスクロールで移動する。ピンチと ⌘+スクロールで拡大縮小する。
- 文字キーで選択中のノードを書き換える。ダブルクリックで編集する。Escape で取り消す。
- ⌘. か、ノードの外側に出る丸をクリックすると枝を折りたたむ。折りたたんだノードには子孫の数が出る。折りたたんだノードに Tab で子を足すと自動で開く。
- Delete で削除、⌘Z で取り消し、⌘⇧Z でやり直し、⌘0 で全体を表示する。
- CLI からの変更は SSE で即時に反映され、⌘Z で取り消せる。
- サーバーがないときは localStorage だけに保存して動く。

## 中身

- `index.html`: データは `nodes`（Map）と `rootId`。`layout()` が目標位置を決め、`frame()` が表示位置を補間し、`draw()` が SVG を更新する。操作の前に `pushUndo()` で状態を JSON で積む。
- `server.mjs`: ページの配信、`GET/PUT /api/map`、`GET /api/events`（SSE）。`data/map.json` の変化を見て配る。
- `cli.mjs` と `lib/map.mjs`: 名前・ID・経路でノードを指して追加・改名・移動・削除・折りたたみ、Markdown の箇条書きの取り込みと書き出し。

## まだないもの

- OPML や `.mindnode` との相互変換
- 複数選択とコピー・ペースト
- 固定したノードどうしの重なり回避
- 同時編集の衝突の扱い（最後に書いたほうが勝つ）
